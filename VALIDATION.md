# Выполненные проверки

Ниже сохранены результаты ранее выполненных проверок. Тестовый проект и вспомогательные каталоги исключены из текущей структуры по запросу при подготовке исходников для GitHub.

В проверке доступности кнопок удалена зависимость от временного `Document.IsReadOnly`: кнопки включаются при открытом документе проекта. Проверка внутри запущенного Revit после этого изменения ещё требуется.

Системная арматура и армирование по площади переведены на геометрическое пересечение осевых линий всех позиций стержней. Вызовы `GetHostId()` из реализации удалены. Поведение на модели Revit после изменения ещё требует проверки.

Сокращена диагностика: недоступная запись (включая вложенные элементы) учитывается как пропуск без поэлементной ошибки. Подтверждённое отсутствие пересечения отделено от отсутствия марки, геометрии и неполных проверок. Для проверки отсутствия пересечения учитываются также конструкции без Марки. Служебные строки геометрического анализа не добавляются в отчёт. Изменения проверены компиляцией; подтверждение на модели Revit ещё требуется.

- Release / x64 / Revit 2019 / .NET Framework 4.7: сборка без ошибок и предупреждений; ссылки итоговой DLL на RevitAPI и RevitAPIUI проверены на основную версию **19**.
- Release / x64 / Revit 2021 / .NET Framework 4.8: сборка без ошибок и предупреждений; ссылки проверены на основную версию **21**.
- 30 независимых регрессионных проверок: исходные 8 правил выбора групп и конструкций; 7 проверок консервативного отсева по габаритам (включая касания, допуск, отрицательные координаты и прямой отрезок); 5 проверок кэша общей геометрии, разделения режимов и очистки состояния; 10 проверок перехода «стена → плита → нижняя стена».
- Для перехода через плиту проверены: приоритет нижней стены при большей длине в других конструкциях, независимость от порядка кандидатов, отсутствие срабатывания без плиты или одной из стен, запрет объединения разных стержней и частей одной стены, плита вне перехода, соседние стены с перекрывающимися диапазонами высот, концы стен внутри толщины плиты. Геометрические данные для правила берутся из реальных пересечений; выполнение на модели Revit ещё требует проверки.
- В проверке кэша использованы 1000 условных стержней и 3 тела с двумя проходами: итоговые суммы совпали с расчётом без кэша; выполнено 3000 расчётов вместо 6000. Это проверка механизма повторного использования вне Revit и не является замером скорости Revit.
- В заполнение добавлены кэши осевых линий, пар пересечений, габаритов и параметров, а также консервативный отсев заведомо раздельных пар. В отчёте отображается время анализа и записи. Фактическое ускорение на модели Revit ещё не измерялось.
- Окно ручных соответствий проверено отдельным WinForms-стендом: ввод значений, пропуск строки из пробелов и завершение редактирования активной ячейки при нажатии «Применить». Выполнена визуальная проверка таблицы, подписей и кнопок.
- Оба установщика проверены в тестовых папках рабочего каталога: контрольная сумма DLL и абсолютный путь в манифесте. Для 2019 также проверено обновление с сохранением предыдущей DLL и манифеста в резервных копиях.
- В установочных папках нет копий RevitAPI.dll и RevitAPIUI.dll: надстройка использует API запущенного Revit.

Существующий проект MyInstrumentsForRevit и рабочие каталоги надстроек Revit не изменялись. Запуск команд внутри Revit на реальной модели ещё не выполнялся. Геометрическую обработку, запись и отмену необходимо проверить на копии проекта.
